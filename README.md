# Baldi's Math Doors

This project is a Roblox game where players open doors to find notebooks with math problems. If the player answers the math problem incorrectly, Baldi Basics kills them. The game features simple addition and subtraction problems, and players must interact with doors and notebooks to progress.

## Install

1. Download the project files from the GitHub repository.
2. Open your Roblox game in Roblox Studio.
3. Place the `DoorsGame.server.lua`, `Baldi.server.lua`, and `Player.server.lua` scripts in the appropriate locations in your game.
4. Ensure you have the necessary models and parts set up in your game, such as doors and notebooks.

## Use

1. Start the game in Roblox Studio.
2. Players must open doors by pressing the 'E' key when looking at a door.
3. When a door is opened, a notebook with a math problem will appear.
4. Players must type the correct answer in the notebook's text box and press 'Enter'.
5. If the answer is correct, the notebook will disappear, and the player can continue.
6. If the answer is incorrect, Baldi Basics will move to the player's location and kill them.
